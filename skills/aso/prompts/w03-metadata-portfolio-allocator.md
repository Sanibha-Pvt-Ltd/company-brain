# Workflow 3 — Metadata Portfolio Allocator
Treat App Store metadata as scarce inventory.

The objective is not to stuff as many keywords as possible.

The objective is to allocate limited metadata space toward the highest-value relevant search demand.

Analyse:

app name

subtitle

keyword field

category

description where relevant to customer comprehension

promotional text where relevant to conversion/messaging

localized metadata

app tags where available

metadata duplication

brand terms

feature terms

problem terms

use-case terms

audience terms

For every candidate keyword assess:

relevance

intent

commercial value

evidence of demand

ranking feasibility

downstream conversion

redundancy

ability to combine with other terms

current placement

opportunity cost

Avoid:

irrelevant keywords

competitor trademarks

unnecessary repetition

vanity terms

terms the product cannot genuinely satisfy

keyword allocations unsupported by evidence

Output
Create:

Metadata Allocation Map
For each keyword or keyword family:

Target intent

Evidence

Recommended placement

Current placement

Keep / Add / Remove / Test

Reason

Opportunity cost

Confidence

Then produce recommended:

App Name Strategy
Subtitle Strategy
Keyword Field Strategy
Category Considerations
Terms to Remove
Terms Requiring Validation
Do not invent search-volume estimates.

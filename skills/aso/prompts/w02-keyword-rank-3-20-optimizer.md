# Workflow 2 — Keyword Rank 3–20 Optimizer
Objective
Improve visibility for queries where Apple already considers the app relevant.

Focus primarily on meaningful queries where the app ranks roughly within positions 3–20, but use judgment rather than rigid cut-offs.

Diagnose:

Weak title relevance

Weak subtitle relevance

Keyword-field allocation problem

Category mismatch

Search-intent mismatch

Product-page positioning mismatch

Creative mismatch

Poor conversion relative to visibility

Weak ratings/reviews

Competitor strength

Lack of product relevance

Localization mismatch

Insufficient evidence

No obvious defect

Do not change metadata automatically because a keyword is not #1.

Consider whether the likely bottleneck is actually:

ranking

or

tap-through

or

download conversion

or

trial conversion

or

monetisation.

Intervention Order
Prefer:

Do nothing where current performance is strong

Improve keyword allocation

Improve subtitle/value proposition

Improve first screenshot/message match

Reorder screenshots

Test creative

Create a Custom Product Page for distinct intent

Improve review-related product issues

Improve app functionality

Reposition more substantially only where evidence supports it

For each opportunity:

Rank

Trend

Intent

Diagnosis

Evidence

Expected mechanism

Effort

Metric to monitor

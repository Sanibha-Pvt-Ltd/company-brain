# Workflow 5 — Product Page Conversion Optimizer
Objective
Increase the probability that a qualified App Store visitor downloads the app.

Do not optimise conversion in isolation from user quality.

Diagnose the product page across:

icon

app name

subtitle

rating

rating volume

first screenshot

second screenshot

screenshot narrative

proof

use-case clarity

differentiation

feature presentation

app previews

description

promotional text

trust signals

pricing expectations where visible

review themes

localization

Ask:

What does the user believe they are getting within the first few seconds?

Evaluate whether the listing clearly communicates:

problem solved

key benefit

target user

differentiation

proof

expected experience

Avoid generic advice such as:

"make screenshots more attractive."

Instead prescribe specific hypotheses.

Example structure:

Hypothesis: Visitors searching for duplicate-photo cleanup respond better to an outcome-led first screenshot than a broad storage-management claim.

Test: Screenshot 1A vs 1B.

Primary metric: Product page conversion.

Secondary metrics: install quality, trial starts, paid conversion.

Output
Conversion Diagnosis
Above-the-Fold Problems
Screenshot-by-Screenshot Analysis
Messaging Opportunities
Trust / Proof Gaps
Recommended Experiments

Variable

Control

Treatment

Expected mechanism

# Workflow 4 — Search Intent & Product Page Mapper
Objective
Determine whether different search intents should use:

the default product page

the same listing message

separate Custom Product Pages

separate localization

a different app entirely

no targeting

Primary evidence should be actual user intent and App Store results, not linguistic similarity alone.

For query groups analyse:

search-result overlap

apps repeatedly ranking

dominant app positioning

product type

use case

audience

problem

buyer expectation

visual messaging

feature expectation

monetisation fit

whether the same product experience satisfies both queries

Classify:

SAME INTENT

CLOSE INTENT — SAME LISTING

DISTINCT INTENT — CPP CANDIDATE

DISTINCT PRODUCT NEED

UNCERTAIN

Prefer fewer strong experiences over unnecessary fragmentation.

Output
Create the minimum viable intent map:

Intent cluster

Primary keyword

Supporting keywords

User need

Buyer stage

Default page / CPP / localization / separate product

Core message

Hero screenshot concept

Deep-link destination if relevant

Cannibalisation risk

Confidence

Then provide:

Intents That Should Share Messaging
Intents Worth Separate CPPs
Intents the Product Should Not Target
Intents Requiring More Evidence

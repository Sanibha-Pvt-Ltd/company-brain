# Workflow 1 — App Store Demand & Money Keyword Miner
Objective
Find search demand that Apple is already exposing the app to, or that competitors demonstrate exists, but which the app is not capturing effectively.

Analyse every meaningful keyword/query using available evidence such as:

keyword

search intent

problem being solved

buyer stage

current rank

historical rank

relevant competitor ranks

Apple Ads search-term performance

impressions where available

taps

installs

product-page conversion

trial rate

paid conversion

revenue

retention

relevance to actual app functionality

Prioritise keywords showing combinations of:

strong product relevance

commercial value

existing Apple validation

rankings within striking distance

meaningful paid-search conversion

strong downstream monetisation

clear user intent

competitor validation

weak current listing alignment

Classify each opportunity:

Improve metadata

Improve listing/message alignment

Improve creative

Target through Custom Product Page

Test via Apple Ads first

Target through localization

Build product feature before targeting

Monitor

Ignore

Do not target a keyword simply because it appears popular.

Do not target irrelevant keywords merely to obtain impressions.

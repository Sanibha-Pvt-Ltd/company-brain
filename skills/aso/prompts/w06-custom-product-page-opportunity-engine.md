# Workflow 6 — Custom Product Page Opportunity Engine
Objective
Determine where separate App Store experiences can improve intent matching and acquisition efficiency.

Consider CPPs for:

distinct use cases

distinct audiences

distinct features

distinct problems

paid acquisition campaigns

search intents

seasonal campaigns

regional positioning

referral campaigns

Do not create CPPs simply because the capability exists.

For each proposed CPP assess:

size of addressable intent

distinctness from default page

acquisition source

keyword evidence

paid-search evidence

conversion opportunity

creative differentiation

product destination

monetisation potential

maintenance burden

When deep linking is available and relevant, consider whether the CPP should lead users into the corresponding in-app experience.

Output
For each proposed CPP:

CPP theme

Audience / intent

Keyword set

Acquisition source

Core proposition

Screenshot concept

Promotional message

In-app destination

Expected mechanism

Success metric

Priority

Confidence

Classify:

BUILD

TEST

HOLD

DO NOT BUILD

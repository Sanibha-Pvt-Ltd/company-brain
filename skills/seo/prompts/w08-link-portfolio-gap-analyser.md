# Workflow 8 — Link Portfolio Gap Analyser
Analyse backlinks as a portfolio.

Evaluate:

topical relevance

geographic relevance

publisher type

real visibility

editorial context

page relevance

authority

placement

anchor diversity

link type

persistence

source diversity

competitor overlap

acquisition-channel concentration

Look for diminishing returns.

Possible link classes:

niche editorial

major media

smaller real blogs

geo-specific publishers

podcasts

directories/reference sources

industry organisations

partnerships

digital PR

relevant niche edits

community/UGC mentions

Do not recommend buying/acquiring links merely because a domain exceeds an arbitrary authority threshold.

Existing strengths

Concentration risks

Competitor consensus opportunities

# Workflow 3 — Internal Link Capital Allocator
Treat internal links as capital allocation.

Evaluate potential donor pages using:

Semantic relevance

Existing Google visibility

External authority

Organic traffic/impressions

Position in site hierarchy

Probability the link genuinely helps users

Existing internal-link load

Whether donor already links to target

Anchor-text concentration

Reject:

irrelevant donors

boilerplate navigation disguised as recommendations

footer links presented as contextual opportunities

forced anchors

duplicates

unrelated pages

Do not assume existing internal links should remain indefinitely.

Consider whether established ranking pages need less support and whether some authority could be reallocated.

Output
Source URL

Target URL

Why source is relevant

Source strength

Existing link status

Recommended anchor style

Placement context

Priority

Confidence

Then provide:

Best Donor Pages
Under-Supported Money Pages
Reallocation Opportunities
Anchor Risks
Structural Problems
Finish with implementation order.

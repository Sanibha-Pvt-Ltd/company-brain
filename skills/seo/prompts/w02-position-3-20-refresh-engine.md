# Workflow 2 — Position 3–20 Refresh Engine
Objective:

Improve pages Google already considers relevant using the smallest defensible changes.

Focus primarily on queries/pages ranking approximately 3–20.

Diagnose:

Search-intent mismatch

Page-type mismatch

Query not explicitly answered

Important answer buried too deeply

Weak heading/query alignment

Missing subtopic or entity

Weak internal-link support

Weak title/SERP appeal

Cannibalisation

Insufficient external authority

Outdated information

No meaningful defect detected

Do not rewrite the whole page by default.

Output
For each opportunity:

Query

Current position

Current URL

Diagnosis

Evidence

Smallest recommended change

Why it may help

Effort

Risk

Confidence

Measurement required

Then divide implementation into:

DO FIRST
High-upside, relatively low-effort changes.

TEST
Changes with a plausible mechanism but meaningful uncertainty.

LEAVE ALONE
Pages where editing may destroy something already working.

Never claim a ranking improvement is guaranteed.

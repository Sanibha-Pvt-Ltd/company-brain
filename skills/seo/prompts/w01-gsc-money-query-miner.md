# Workflow 1 — GSC Money Query Miner
Objective:

Find commercially valuable search demand Google is already exposing the website to but which the website is not properly capturing.

Analyse meaningful queries using:

buyer stage

commercial intent

modifier

ranking URL

average position

impressions

clicks

CTR

relationship to the actual revenue-generating offer

Prioritise:

rankings approximately 3–20

meaningful impressions

commercial intent

comparison intent

problem-solving intent

decision intent

pages only partially satisfying intent

recurring query families

queries Google appears to be testing despite the site not deliberately targeting them

Classify every meaningful opportunity:

Improve existing page

Create dedicated page

Merge/consolidate competing pages

Internal-link opportunity

Title/CTR opportunity

Supporting-content opportunity

Ignore

Never create new URLs merely because keyword wording differs.

Only separate URLs where search intent, page type, buyer stage or commercial purpose differs materially.

Output
Return a table containing:

Query

Query cluster

Current URL

Position

Impressions

Clicks

CTR

Buyer stage

Commercial intent

Opportunity type

Recommended action

Target URL

Reason

SERP validation required

Confidence

Then provide:

Top Money Opportunities
Identify the strongest commercial opportunities using:

commercial value × existing Google validation × probable ease of improvement

Existing Pages to Improve
New Pages Worth Creating
Cannibalisation Risks
Queries to Ignore
Finish with the first five actions the operator should take.

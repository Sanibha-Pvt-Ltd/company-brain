# Workflow 4 — Serp Intent Splitter
Primary evidence:

What search engines actually return.

For each query pair evaluate:

overlap between ranking URLs

dominant page type

informational vs commercial intent

buyer stage

result composition

recurring concepts/entities

SERP features

modifier meaning

whether the modifier materially changes user intent

whether one page can genuinely satisfy both searches

Classify relationships as:

SAME INTENT

CLOSE INTENT — ONE PAGE

SEPARATE INTENT

UNCERTAIN

Prefer fewer stronger URLs over unnecessary fragmentation.

Do not make final clustering decisions without SERP evidence.

Output
Create the minimum viable URL map:

Recommended page

Primary query

Supporting queries

Search intent

Buyer stage

Page type

Commercial purpose

Why queries belong together

Why separated queries need different URLs

Cannibalisation risk

Confidence

Then provide:

Queries That Should Share a Page
Queries That Need Separate Pages
Queries Requiring More SERP Evidence
Existing URLs to Consolidate or De-Optimise

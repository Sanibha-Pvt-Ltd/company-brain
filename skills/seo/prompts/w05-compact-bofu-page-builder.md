# Workflow 5 — Compact BOFU Page Builder
Objective:

Create the smallest commercial page that completely satisfies the buyer's decision.

Determine what the buyer needs before taking action.

Prioritise:

exact service/product match

availability

location

pricing or pricing mechanism where relevant

differentiators

trust

proof

process

specifications

objections

CTA

Remove unnecessary:

generic introductions

history lessons

long definitions

repeated conclusions

redundant FAQs

educational tangents

prose written merely to increase word count

Do not target arbitrary word counts.

Let intent determine depth.

Never invent:

testimonials

reviews

certifications

guarantees

prices

statistics

product capabilities

stock

delivery details

claims of expertise

Output
Primary intent

Buyer stage

Recommended page type

Core value proposition

Above-the-fold components

Required sections

Optional sections

Proof assets required

Objections to address

CTA

Internal links into page

Internal links out

Structured data where appropriate

Missing business information

Then produce the page outline.

Finally identify anything competitors appear to overdo that this page can avoid.

# Workflow 10 — SEO Experiment Designer
Convert uncertain SEO tactics into the cheapest useful controlled experiment.

Never assume something works because:

an SEO expert says so

a podcast discussed it

a case study reported it

competitors appear to do it

it is popular on social media

Required Experiment Structure
Hypothesis
State precisely what is being claimed.

Plausible Mechanism
Explain why it could work without presenting the mechanism as proven.

Test Asset
Choose an asset with appropriate risk.

Test Group
Identify pages/sites/queries receiving the intervention.

Control Group
Identify what remains unchanged.

Variable
Change one meaningful variable wherever possible.

Metrics
Specify what will be measured.

Examples:

rankings

impressions

clicks

CTR

indexation

conversions

revenue

AI citations

Confounders
Identify factors capable of creating false positives or negatives.

Observation Window
Choose a sensible period based on the intervention.

Success Threshold
Define what would justify repeating/scaling.

Failure Threshold
Define what would justify stopping.

Reversibility
Explain how easily the intervention can be undone.

Risk
State the downside if the hypothesis is wrong.

Scale Plan
Explain how testing expands only after evidence supports it.

Finish with one:

TEST IT

TOO CONTAMINATED TO TEST

TOO RISKY FOR THIS ASSET

NOT WORTH TESTING

ALREADY ANSWERABLE FROM EXISTING DATA

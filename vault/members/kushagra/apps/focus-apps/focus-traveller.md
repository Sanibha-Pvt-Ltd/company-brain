## Eight lens dimensions

1. **First win:** A clear task prompt and Go button appear on New Journey (p.6–7), and a rest scene is captured later (p.13–14), but stats show 0 sessions / 0 streaks (p.20–23). Successful focus outcome and exact taps are [UNKNOWN].
2. **Ask ledger:** push opt-in (p.2), Traveller name (p.3), optional-looking social group (p.5), focus task (p.6), Pro appears by p.8, rating prompt p.15. Screenshot order only; no confirmed single path.
3. **Abstractions:** Single vs Multi, Traveller/avatar name, journeys, partners, Pomodoro/Deep Focus, streaks, session stats, reward “Guide” labels and group (p.3–24). A single task plus start/rest is the simplest core loop; social travel system can be optional. [INFERRED]
4. **Feel-good:** Focus timer is framed as a journey; a rest landscape and collectible boot communicate a calm end-state (p.12–14). “Great time to take another step ahead” is supportive (p.4). These are tied to a focus session, but completion is not proven.
5. **Feel-bad:** Deep Focus mode automatically sends Traveller to rest if the user leaves and waits (p.10); five-star rating ask (p.15) interrupts home. Neither streak loss nor hidden close is shown.
6. **Paywall:** Pro screen p.8 offers ₹99 monthly, ₹799/year with 3-day free trial, or ₹1,499 lifetime. Close X shown; native renewal sheet is not captured. US prices are [UNKNOWN]; storefront is not independently verified. Whether basic session is gated is unknown.
7. **Repeat cost:** [UNKNOWN] exact taps. Timer settings permit default duration/rest and Pomodoro (p.16); quick Go action p.6. Return hooks include journey, travel group, friend ranks, items, stats and streaks (p.5, p.13–14, p.19–24).
8. **Feature map:** Table stakes: focus timer, task intention, pause/rest, session history. Differentiator: journey map, Traveller partnership and rest-scene narrative (p.6, p.13–14, p.20–24). Bloat risk: requiring avatar naming or social comparison before timer use, and reward taxonomy on first use. [INFERRED]

## Keep / Kill / Different

- **Keep:** One clear task prompt before starting (p.6), rest/breathing pause (p.11–14), and lifetime option alongside subscription (p.8).
- **Kill:** Do not make group creation or partner selection feel mandatory for a solo session (p.5, p.20–21). Avoid rating ask until after a confirmed focus outcome (p.15).
- **Different:** Start with task + timer and allow the user to choose a scenic/avatar layer later. If blocking is enabled, offer a gentle pause state and preserve session progress after leaving the app. [INFERRED]

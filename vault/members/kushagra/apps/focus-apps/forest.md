## Eight lens dimensions

1. **First win:** The first tree screen shows 0:01 (p.6), but no completed focus session or successful outcome can be inferred. The first later goal requires completing one focus session and another task (p.18); no taps or timing is established.
2. **Ask ledger:** distraction selection + Screen Time permission (p.3–5); reminder prompt (p.7); account (p.9); Plus trial (p.10–14); gift/planting, repeated Plus pitch and starter tasks (p.15–20); another Screen Time/Time Guard setup (p.26–32). Screenshot sequence may include separate app surfaces, so not one confirmed journey.
3. **Abstractions:** block list, tag, Forest/Plus, trial, species/land, coins/crystals, daily rewards, Time Guard, focus duration, rankings and real-tree claims (p.3–48). App blocking maps to user's stated distraction; currencies, two focus-area surfaces and tour systems are additional concepts. [INFERRED]
4. **Feel-good:** Growing tree is tied to focus timer (p.6, p.16); Welcome Gift tree and first-focus reward checklist provide tangible goals (p.15, p.18–20). The user must complete tasks before reward unlock, which can earn the moment.
5. **Feel-bad:** Two Screen Time/setup contexts can make configuration feel repetitive (p.5, p.26–32). “3x richer with Plus” and paid claim “Will you be next?” (p.12, p.17) lean on social proof. Trial walls use “Try for $0” alongside ₹ renewal; clarify currency on the CTA.
6. **Paywall:** Plus offer p.10–14: one-week free trial then ₹1,299/year, annual billing; crossed-out ₹2,499/year, 48% off on p.12. Native sheet p.14 corroborates trial and yearly amount. Close X visible in offer pages. Another free promo appears p.17, exact terms not fully visible there. Amounts are displayed in ₹; storefront is not independently verified.
7. **Repeat cost:** Exact taps unknown. Return cues: reminder, growing forest, daily/seasonal quests, species, friends/rankings, stats and real-tree contribution page (p.7, p.15–25, p.37–42). Need completed and repeated session capture to count interactions.
8. **Feature map:** Table stakes: focus timer, optional blocking, tags, history. Differentiators: forest growth, starter challenge/gift, focus stats, real-tree initiative claim (p.6, p.15, p.18–25, p.42). Bloat risk: duplicate permission setup, multiple currencies, extra Time Guard, ranking/news/shop modules before a repeat habit (p.26–48). [INFERRED]

## Keep / Kill / Different

- **Keep:** Ask Screen Time permission with direct explanation at the moment user chooses app blocking (p.3–5); “Maybe later” on reminder and optional welcome gift (p.7, p.15); clear native trial renewal terms (p.14).
- **Kill:** Don't present Screen Time setup a second time without explaining why the earlier permission did not suffice (p.5, p.26–32); avoid currency-mixing $0 CTA with rupee renewal (p.10–14). Don't make the first timer dependent on trial acceptance.
- **Different:** Show one short focus session and its tree state first. Ask for block-list access only when user opts in; explain any second permission with a concrete need. Surface one trial offer with same-currency charge, term, billing cadence and clear close.

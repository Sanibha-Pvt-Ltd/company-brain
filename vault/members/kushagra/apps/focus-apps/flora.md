## Eight lens dimensions

1. **First win:** Starting focus is visible at home p.4, but the supplied screens show stats at zero (p.19) and no completed first focus session. First meaningful outcome, screen/tap count, and whether a tree survives are [UNKNOWN].
2. **Ask ledger:** signup/login precedes home in the capture (p.2–3); task creation appears before Start Focus (p.4–5); tree/Bits/tours screens p.6–10; friend invites and settings p.11–15; session configuration p.16–18. Screens do not prove a single path or required status. Value received at most is an editable to-do/focus setup.
3. **Abstractions:** To-do goals and reset cadence, trees/species, tours/regions, Bits currency, friends, garden, “tree killed” state, Flora Care (p.4–18). Task name and duration are core; Bits, unlockable worlds and life-growth metaphor are extra concepts. [INFERRED]
4. **Feel-good:** Focus is linked to a plant/tree growing, and the breathing screen gives a calm cue (p.16–18). Bits are explained with a transparent exchange rule (one focused minute = one Bit, p.9), which can make progress legible.
5. **Feel-bad:** “Tree killed if you left the app” (p.17) threatens loss after interruption. Account signup ahead of first focus (p.2–3) adds cost. No hidden-close or trial trick is evident.
6. **Paywall:** No subscription wall is visible in the supplied flow. Two optional tour purchases cost ₹199 each (p.21–22). US pricing and other paid surfaces are [UNKNOWN].
7. **Repeat cost:** Exact taps unknown; homepage has Start Focus, add-to-do and bottom tabs (p.4). Repeat hooks: reminder, garden, tree growth, friend list and stats (p.5, p.10–11, p.19). Need an actual completed session to count core path.
8. **Feature map:** Table stakes: focus timer, task name, interruption settings, session history. Differentiator: social garden / real-tree contribution claim, environmental tour theme, breathing (p.6–11, p.18). Bloat/cost: account first, Bits/shop/world navigation and guilt for leaving app (p.2–3, p.6–10, p.17). [INFERRED]

## Keep / Kill / Different

- **Keep:** Start Focus is prominent and task setup stays lightweight (p.4–5); duration, break and app allowance are configurable (p.12, p.16–17); breathing break is a relevant recovery cue (p.18).
- **Kill:** “Tree killed if you left the app” consequence (p.17). Don’t force account creation before a first focus session if it is not technically needed (p.2–3).
- **Different:** Reward returning to focus after an interruption; preserve the tree and show a neutral pause/restart state. Keep task and timer on the first screen, with Bits/shop as optional later discovery. [INFERRED]

## Eight lens dimensions

1. **First win:** A 5-second tutorial demo (p.15–16) precedes a 5:00 timer screen (p.19), but these screens don’t prove a completed session. A reward screen appears at p.18; because this is tutorial sequence, exact outcome/taps remain [UNKNOWN].
2. **Ask ledger:** focus-use selection and daily phone estimate (p.4–5); Screen Time permission for a personal report (p.6); trial/annual plan (p.13); commitment (p.10–11); app blocking choice (p.17); notification permission (p.29). Each appears before a complete real session is evidenced. Exact transitions/taps are not established.
3. **Abstractions:** personal screen-time report, focus commitments, trial, raindrops, land, plant/water, app-lock mode, reward cutoff, history, sync, Pomodoro, stopwatch (p.4–37). Basic task + timer can stand on its own; game economy and modes are optional systems. [INFERRED]
4. **Feel-good:** Visual sprout growth, water-to-plant tutorial, and “new sprout” celebration map to completed actions (p.20–24). “Congratulations” after onboarding (p.12) precedes a demonstrated session, so it is manufactured encouragement rather than earned focus progress. [INFERRED]
5. **Feel-bad:** Personal-data request precedes report; report’s “34.7%” reduction claim is not substantiated inside the screenshot (p.6–9). “No rewards” before 5 minutes (p.32) and one-time offer expiry (p.27) create pressure. The copy says “offer will be gone forever upon exiting this window.” [OBSERVED]
6. **Paywall:** p.13 trial offer: 7 days, then ₹759/year; p.27 one-time 25% offer ₹569/year after 7 days, ₹ is displayed; storefront is not independently verified. Both show close X; “No payment required today” and trial end/renewal disclosed. The second offer is an observed different offer, trigger unknown; do not assume exit caused it.
7. **Repeat cost:** Exact taps unknown. Timer modes include countdown, Pomodoro and stopwatch (p.15, p.36–37); history provides a recap (p.33). Return cues include plant growth and optional notification reminder (p.23–29). Need a live session and second session to count.
8. **Feature map:** Table stakes: duration/task timer, optional app block, session history. Differentiator: plant growth tied to focused time and app-block choice (p.17–24). Bloat/cost: Screen Time diagnostic intake before timer, speculative personalized report, multiple currencies/modes and reward cutoff (p.4–9, p.21, p.32–37). [INFERRED]

## Keep / Kill / Different

- **Keep:** Show exactly what Screen Time permission unlocks before asking (p.6); offer app blocking both with and without lock (p.17); plant/water reward is a clear visual metaphor (p.20–24); trial screen states renewal and offers a reminder toggle (p.13).
- **Kill:** Don’t present the unverified 34.7% reduction as personalized result (p.8–9). Don’t withhold all rewards for a short interrupted session (p.32) or use “gone forever” one-time urgency (p.27).
- **Different:** Let a user start a simple focus session before Screen Time access; introduce app blocking at the moment they choose it. Reward the effort proportionally even if a session ends early, and label personal reports with their data source. [INFERRED]

# Members

One folder per person: `members/<name>/apps/<category>/<app>.md` for stage A teardowns, `members/<name>/drafts/` for stage 0/B/C/E/D output. A member's key writes only here, so two people can never overwrite each other. Everyone can read everything.

Promotion: an admin (Bharat or Harshil) copies a reviewed draft to its canonical path under `research/` and logs it in [[logs/decisions]].

Folders are created by the first write — no setup needed. Names are lowercase first names, matching the key name minted for the person.

Vault ownership: Harshil manages the vault. `knowledge/` is read-only for everyone else.

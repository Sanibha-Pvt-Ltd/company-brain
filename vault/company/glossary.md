# Glossary

- **Stage 0 / A / B / C / E / D** — the research agent's stages: lens, app deep-dive, market, MVP, portfolio, build spec.
- **Failure mining** — clustering 1–2★ reviews into complaint themes to find what incumbents get wrong.
- **Promote** — an admin copies a reviewed draft from `members/<name>/drafts/` to its canonical path under `research/`.
- **MVP draft / final** — `status` in frontmatter; final only after team review and Bharat's sign-off.
- **Evidence tags** — OBSERVED, DATA, REVIEW, ESTIMATE, INFERRED, UNKNOWN.
- **Time-to-value** — taps from first launch to the first useful result.
- **RPD** — revenue per download.

# Sanibha company brain

Shared vault for Sanibha Pvt. Ltd.: research, decisions, specs. Served by the brain MCP server; open `vault/` in Obsidian.

- `skills/app-researcher/` — research agent (see `RUNBOOK.md`)
- `skills/aso/`, `skills/seo/` — ASO and SEO operators (SKILL.md + `prompts/` per workflow)
- `tools/fetch-app.py` — pulls App Store reviews for an app
- `vault/` — the notes; open this folder in Obsidian. Each member writes only in `vault/members/<name>/`
- Server code lives in the separate `brain-mcp` repo

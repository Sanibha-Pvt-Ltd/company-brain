Document Scanner

1. Scanner App
Onboarding & First-Time Experience
* Onboarding requires multiple clicks/steps.
* After trying both the camera and file-upload options, switching between them feels smoother/easier.
* No mandatory sign-in.
* No immediate paywall.
* Some usage/input limits are communicated to the user.
* When the user is nudged toward the premium plan, the free trial appears to start automatically.
Pricing / Monetization
* 7-day access for ₹49, followed by approximately ₹999/week.
* Another pricing point of around ₹1,499/week was also observed.
* The pricing feels quite aggressive for what could often be a one-time-use utility app.
Product Experience
* Basic functionality is straightforward: scan documents and create PDFs.
* The UI is very clean and simple.
* The app focuses primarily on getting the scanning task done without unnecessary complexity.

2. iScanner
Onboarding
* The app took some time to load initially.
* Around a 4-step/click onboarding flow.
* Users are repeatedly nudged toward the paid plan.
* The option to cancel/close the subscription screen felt somewhat camouflaged or intentionally less prominent.
Pricing
* 7-day free trial, followed by approximately ₹599/week.
* Another pricing option of around ₹1,499/week was also observed.
Features
The app offers several utilities beyond scanning:
* Document scanner
* Fax
* PDF editing
* AI tools
* Invoice-related tools
* File import
* Gallery import
* Camera scanning
The app presents multiple actions such as Fax, Invoice, Scan, etc., which then redirect users into the respective tools.
Scanning & Paywall
* Scanning appears to be available for free for around one page / limited usage.
* After that, the paid plan is shown or promoted heavily.
* The premium plan is progressively nudged throughout the experience.
UI/UX
* Direct access to Files, Gallery, and Camera is very useful.
* The UI is visually a little unusual, but it is effective and functional.
* Overall navigation and action discovery are quite good.

3. Adobe Acrobat – PDF Suite
Onboarding
* Very clean onboarding experience.
* No unnecessary questions or permission requests at the beginning.
* A sign-up/sign-in screen appears on the first screen, although there is an option to close/skip it.
* There is still some nudging toward creating an account.
Pricing / Paywall
* Creating certain PDFs/features requires payment.
* 7-day free trial.
* Approximately:
    * ₹2,599/year
    * ₹599/month
Free / Available Features
Some functionality can be accessed without immediately subscribing, including:
* PDF viewing
* Signing PDFs
* Generating a podcast from a document
* Read Aloud
UI/UX
* Very clean and basic interface.
* Despite the simple UI, several AI-powered options are available.
* Overall, Adobe keeps the interface uncluttered while exposing advanced features when needed.

4. Adobe Scan
Onboarding & Account Requirement
* The app cannot really be used without signing up/signing in.
* After signing in, a paywall is shown, although it can be skipped.
* The onboarding takes roughly 3 interactions/clicks, including permissions such as:
    * Camera access
    * Notifications
Pricing
Two paid plans were observed:
* Premium – approximately ₹849/month
* Plus – approximately ₹499/month
* 7-day free trial available.
Scanning Experience
* After onboarding, the user is taken directly into the scanning experience.
* Creating/scanning a basic PDF is free.
* Some additional PDF functionality is restricted.
Free vs. Paid Features
Basic scanning and PDF creation are available, while more advanced tools are pushed behind the paid plan.
Observed premium-oriented features include:
* Edit Text
* Magic Eraser
* Cleanup / enhancement tools
Monetization Behaviour
* The app repeatedly nudges users toward the free trial.
* The paywall appears early, but it is still skippable.
* Adobe uses feature restrictions rather than completely preventing users from performing a basic scan
